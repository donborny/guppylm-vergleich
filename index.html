Checkpoints vergleichen

Dieselbe Frage geht an zwei Trainingsstände desselben Modells (ca. 11,7 Mio. Parameter). Gerechnet wird komplett in deinem Browser, es wird nichts an einen Server geschickt. Bei gleichem Seed bekommen beide Seiten dieselben Zufallszahlen beim Sampling, sodass Unterschiede in der Antwort von den Gewichten kommen. Mit Temperatur 0 wird immer das wahrscheinlichste Token gewählt. Deinen eigenen trainierten Transformer kannst du unten als .pt-Datei dazuladen.

Leerer Seed = echter Zufall. Mehrere Durchläufe nutzen Seed, Seed+1, … auf beiden Seiten. top_k = 0 schaltet den Filter ab. Jeder Checkpoint wird beim ersten Gebrauch geladen (ca. 23 MB).
